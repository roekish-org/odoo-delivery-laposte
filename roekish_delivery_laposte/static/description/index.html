La Poste for Odoo 19: Colissimo and Delivengo

Rate shipments, generate labels and customs documents, track parcels and offer pickup-point delivery from Odoo.

Features

RatingDelivery price computed from a Colissimo tariff grid (weight by zone) or from Odoo's native pricing rules.
Delivery timeAnnounced delivery time in working days (minimum and maximum), set on the carrier and overridable per zone in the tariff grid. Returned with every quote and shown in the shipping wizard, so carriers can be compared on cost and speed.
LabelsColissimo label generation through roulier, with the tracking number stored on the delivery order.
TrackingA La Poste tracking link (laposte.fr) is exposed to the customer, for Colissimo and Delivengo parcels.
Pickup pointsSearch nearby pickup points (Colissimo Point Retrait web service) and select one on the quotation or the delivery order, propagated on confirmation.
DelivengoA second provider for international small goods up to 2 kg. Labels and CN22/CN23 customs documents come from the MyDelivengo REST API (Delivengo easy or Profil accounts), shipments can be cancelled from Odoo, and no extra library is needed.

Carriers and zones

Five ready-to-use carriers ship with the 2026 public rates as editable demo data. Replace them with your own negotiated rates.

Colissimo HomeColissimo Pickup PointColissimo Overseas EconomyColissimo Prepaid (Prêt-à-Envoyer)Delivengo easy

Colissimo zones cover metropolitan France (with Monaco and Andorra), Overseas zones 1 and 2, the European Union with Switzerland, the United Kingdom, and international zones B and C.

Delivengo is priced on two zones, the European Union with the United Kingdom and the rest of the world, with four weight bands up to 2 kg.

Security

  • Colissimo credentials and the Delivengo API key are restricted to the La Poste Administrator group, and secrets are masked in error messages.
  • Fine-grained access rights with dedicated User and Administrator groups.
  • Multi-company isolation on the tariff grids.

Requirements

The module builds on Odoo's native delivery framework. Rating works with no external library. Colissimo label generation uses roulier and pickup-point search uses zeep; both libraries are optional and imported on demand. Delivengo only needs requests, shipped with Odoo.

Deploy the module on the addons_path (Odoo.sh or On-Premise). The Apps > Import Module zip upload is data-only and cannot install a module that ships Python models. On Odoo Online (SaaS) Python libraries cannot be installed either, so label generation and pickup-point search need Odoo.sh or On-Premise, where roulier and zeep are available.
