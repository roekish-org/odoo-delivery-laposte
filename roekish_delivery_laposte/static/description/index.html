La Poste / Colissimo for Odoo 19

Rate shipments, generate labels, track parcels and offer pickup-point delivery, straight from Odoo.

Features

  • Rating: delivery price computed from a Colissimo tariff grid (weight by zone) or from Odoo's native pricing rules.
  • Labels: Colissimo label generation, with the tracking number stored on the delivery order.
  • Tracking: a Colissimo tracking link is exposed to the customer.
  • Pickup points: search nearby relay points and select one on the sale order or the delivery order, propagated on confirmation.

Carriers and zones

Four ready-to-use carriers ship with the public Colissimo 2026 tariffs, which you replace with your own negotiated rates: Home, Pickup Point, Overseas Economy and Prepaid (Pret-a-Envoyer). Zones cover metropolitan France, Overseas (zones 1 and 2), the European Union with Switzerland, the United Kingdom, and international zones B and C.

Security

  • Colissimo credentials are restricted to the La Poste Administrator group, and secrets are masked in error messages.
  • Fine-grained access rights with dedicated User and Administrator groups.
  • Multi-company isolation on the tariff grids.

Requirements

The module builds on Odoo's native delivery framework. Rating works with no external library. Label generation uses roulier and pickup-point search uses zeep; both libraries are optional and imported on demand.

On Odoo Online (SaaS), installing Python libraries is not possible, so only rating works there. Label generation and pickup-point search require Odoo.sh or an On-Premise install, where roulier and zeep can be installed.
